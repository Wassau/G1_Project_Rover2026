📡 Protocolo de Comunicación XML (Global)

Definición oficial de mensajes para la integración del Rover (DSMI 2026)

1. Conexión (Init) USER -> CORE

USER-PC / PAD / VISU ➔ CORE (CommTcpIpServer)
Primer mensaje que envía cualquier cliente al conectarse al WiFi. CORE usa esto para guardar quién es y saber a quién enviarle los datos.
<Init>
    <Client>USER-PC</Client>
</Init>

2. Orden de Movimiento USER -> CORE -> PATH

USER-PAD / PC ➔ CORE ➔ PATH (MovimCarro)
Orden de movimiento. VelY controla la velocidad de avance (adelante/atrás). VelX controla el ángulo de dirección (izquierda/derecha).
<MoveCar>
    <VelX>0.5</VelX>  <!-- -1.0 a 1.0 -->
    <VelY>0.8</VelY>  <!-- -1.0 a 1.0 -->
</MoveCar>

3. Cambio de Timer USER-PC -> CORE -> PATH

USER-PC ➔ CORE ➔ PATH (OnSetTimerInterval)
Permite al usuario cambiar la frecuencia de refresco de la odometría. Por defecto será de 100 ms.
<SetTimer>
    <t_ms>50</t_ms>
</SetTimer>

4. Movimiento Cámara USER -> CORE -> PWM

USER-PAD / PC ➔ CORE ➔ PWM (MovimPanTilt)
Controla los servomotores de la cámara (Pan: giro horizontal, Tilt: inclinación vertical).
<MovePanTilt>
    <PanAngle_deg>90.0</PanAngle_deg>
    <TiltAngle_deg>-30.0</TiltAngle_deg>
</MovePanTilt>

5. Estado del Rover PATH -> CORE -> USER/VISU

PATH (MovimCarro) ➔ CORE ➔ USER / VISU
Enviado cada Tm_ms. Informa a la interfaz gráfica y al M5-Stack sobre la posición real del rover y la orientación (Theta).
<Status>
    <Position>
        <X_mm>120.5</X_mm>
        <Y_mm>-450.2</Y_mm>
        <Theta_deg>45.0</Theta_deg>
    </Position>
</Status>

6. Configuración Inicial CORE -> PATH / PWM

CORE ➔ PATH / PWM
Enviado al arrancar el sistema. CORE lee el config.xml y le pasa a cada subsistema los puertos serie y parámetros físicos.
<Config>
    <Path>
        <PortLeft>/dev/ttyUSB0</PortLeft>
        <Wheelbase_mm>330.0</Wheelbase_mm>
        <TrackWidth_mm>240.0</TrackWidth_mm>
    </Path>
</Config>

7. Parada de Emergencia USER -> TODOS

USER-PAD / PC ➔ CORE ➔ PATH / PWM
Detiene inmediatamente todos los motores del rover y los servos de la cámara.
<EmergencyStop>
    <Active>true</Active>
</EmergencyStop>
